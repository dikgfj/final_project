# 데이터로 진단하는 업무지구: 판교테크노밸리 vs 화성 동탄테크노밸리 비교분석

## 🛠 데이터 전처리 과정 (재현 가능성)
본 프로젝트는 원시 데이터(Raw Data)를 웹에서 즉시 시각화할 수 있는 경량 GeoJSON 포맷으로 가공하기 위해 파이썬(Python) 기반의 데이터 파이프라인을 구축했습니다.

### 1. 건축물대장 정밀 공간 조인 (`generate_real_buildings.py`)
- **VWorld 지오코딩 캐싱:** 대용량 주소 데이터를 좌표로 변환할 때 발생하는 API 차단(Throttling) 및 지연을 방지하기 위해 로컬 JSON 기반 캐시(`geocode_cache.json`)를 도입했습니다.
- **`sjoin_nearest` 알고리즘:** 변환된 포인트 좌표와 OSM 건물 폴리곤 간의 미세한 오차를 해결하기 위해, 양쪽 데이터를 모두 한국 표준 투영좌표계(`EPSG:5179`)로 변환 후 반경 50m 이내 최단거리 공간 조인(Spatial Join)을 수행하여 결측치를 최소화했습니다.

### 2. 다익스트라 기반 등시간권 산출 (`isochrone_analysis.py`)
- 제공된 수도권 지하철 네트워크 노드/링크 데이터를 활용해 판교 및 동탄의 '실제 지리적 중심점'에서 출발하는 다익스트라(Dijkstra) 알고리즘을 적용했습니다.
- 30분(1800초) 및 60분(3600초) 도달 가능 노드를 추출한 뒤, 해당 링크를 따라 150m 버퍼를 씌워 하나의 거대한 폴리곤 레이어로 추출했습니다.

### 3. 모듈러 단위(MAUP) 해결을 위한 인구 할당 (`process_population.py`)
- **중심점 포함(Centroid Inclusion) 기준:** 구역계(등시간권 폴리곤)와 SGIS 집계구의 경계가 일치하지 않는 문제를 해결하기 위해, 집계구 폴리곤을 중심점(Centroid)으로 변환한 뒤 등시간권 내부에 포함(`within`)되는 데이터만 추출해 합산했습니다.

## 🤖 AI 활용 내역
본 프로젝트의 핵심 기획과 데이터 분석 파이프라인 설계는 연구자 본인이 수행하였으나, 기술적 구현 과정에서 다음과 같이 생성형 AI 도구의 도움을 받았습니다.
- **파이썬 전처리 로직:** VWorld API 지오코딩 연동, `GeoPandas`의 `sjoin_nearest`를 활용한 정밀 공간 조인 및 다익스트라 등시간권 추출 과정의 프로그래밍 문법 오류 해결
- **프론트엔드 구축:** `Promise.all`을 이용한 비동기 데이터 로딩 및 Fetch 에러 방어 로직, Chart.js를 연동한 UI 구성
